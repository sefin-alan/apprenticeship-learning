# Introduction to The Cloud

## Key Concepts

- Cloud computing is a method of accessing and storing data via the internet, this differs from traditional computing where data is stored on a local computer or server

- It uses virtualisation to create multiple virtual machines within a single physical machine

- This enables many virtual machines to run on one server and so if one server fails, the overall system remains unaffected so that users are still able to access files and services via the internet

**Benefits**

- Reduced IT costs
- accessbility from any internet-connected device, independant from location or physical servers 
- data backup/redundancy

**Drawbacks**

- Reliance on internet connectivity
- cyber security risks due to data being stored online
- server outages could make systems and services unavailable

### Servers and Data Centers

**In-House IT**

Where a company manages and provides hardware, software, and data storage through its own IT team. They're in control of costs but choices, in terms of setup, can be limited. It can also be difficult to keep up-to-date on developing technology, the ongoing investment is high due to maintenance, and the IT team need to be skilled in all areas of the technology

**Cloud Servcices**

Where another organisation provide these services over the internet, there can be higher costs but this comes with the benefit of having more choice as you can change supplier when you want. This also makes it easier to take advantage of new tech.

**Data Centers**

Data Centers are the means of using cloud computing, they are full of identical hardware which runs services, making it easy to scale up and can store data for multiple user organisations. Organisations outsource important services to specialist 3rd party providers who then invest in the hardware and software. Organisations only pay for services they use making them cost-efficient.

**Benefits of Data Centers**

- No hardware or software costs
- computing services can be ordered on-demand, organisations can order what they need, whenever they need it
- generally fast and upgraded to run latest hardware, therefore often quicker than in-house services
- Managed IT Services mean internal IT team can focus on other responsibilities
- 3rd party providers generally have high security capabilities to prevent data breaches

### The Cloud 'As A Service'

**Infrastructure as a Service (IaaS)**

-  An **IaaS** provides servers, storage/data, and firewalls/security
- Organisations can use this to recreate IT infrastructure, define networks, have application servers run inside those networks, and installing and configuring application software on those servers
- Organisation has large degree of control over what software is running in the cloud while provider manages hardware provision

**Platform as a Service (PaaS)**

- A **PaaS** is the means of providing an on-demand environment for developing, testing, delivering and managing software applications, using provider-managed resources
- Organisation has less control over configuration of services but less responsbility for the infrastructure that's running them, increasing their capability to focus instead on adding new services services

**Example:** an organisation needs a database server to capture data from their customer service system. They could use IaaS to create a server and install database management software on it. However, they could also leave this to the cloud provider who can provide and configure the resources, and give the organisation secure access to those resources

**Software as a service (SaaS)**

- A **SaaS** goes the furthest in controlling the cloud services of an organisation, SaaS providers host and manage software applications, underlying infrastructure, and handle any maintenance like software upgrades and seucrity patching.
- The organisation’s only responsibility is for configuring end-user access, and company-specific data and settings. Users access SaaS applications through a user interface and an application programme interface (API) – which enables developers to customise and integrate the software with existing data and applications.  

**Examples of SaaS:** Salesforce.com, Microsoft Office 365 and Google Apps.

**Summary:** When cloud service providers supply infrastructure as a service **(IaaS)**, a resource could refer to a single server. In platform as a service **(PaaS)** a resource could refer to several components working together to provide a single service, and in software as a service **(SaaS)** a resource could be the entire application, or an individual component in that application.

### Benefits of Cloud Services

**On-demand services** can mean more server capacity or application user licenses. There’s no waiting for hardware to be ordered, installed, cabled, and configured before it can be used

**Utility pricing** means that an organisation only pays for resources when they use them. This offers economies of scale, as the scalability of the resources is elastic and can be scaled up and down according to demand. This could look like an organisation altering the power and performance of the resources, perhaps through more memory power, or increasing or reducing the number of resources they're using, like servers and user applications. The option to scale resources is important at times when the IT infrastructure takes a heavier amount of traffic than at another time e.g. when an online game is releasing and the demand for it is not accruately known. In this case, the organisation would need to provision their storage database and network capacity to reflect this additional traffic.

**Elasticity** used in the context of cloud computing relates to the amount of choice cloud services provide an organisation to fully customise their IT environment, and then lets them use only the resources they require.

**Big Data** is easier and cheaper to manage in cloud computing, cloud suppliers provide the resources to handle large, complicated data sets and will offer specialised managed Big Data services to run workloads on and schedule activity. These mean organisations can focus on the data processing and not worry about the maintenance or underlying architecture.
